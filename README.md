# أفكار في 5 دقائق ✦ Ideas in 5 Minutes

> **تطبيق ويب مونوكرومي فاخر للتأمل المركز وتفكيك المفاهيم المعقدة في جلسات خاطفة مدتها 5 دقائق.**  
> *A luxury monochrome web application for focused contemplation and deep concept synthesis in 5-minute sessions.*

---

## 🌟 المميزات الرئيسية | Core Features

### 1. 🔍 عدسات التفكير الثلاث (Mental Lenses)
- **المبادئ الأولى (First Principles):** تفكيك المفهوم إلى عناصره الأولية بدون مصطلحات معقدة.
- **اختبار الضغط (The Stress Test):** استكشاف نقاط الانهيار والثغرات والسيناريوهات القصوى.
- **المستقبل والأثر (Future & Impact):** تحليل ارتدادات الفكرة وأثرها على القرارات والمستقبل خلال 10 سنوات.

### 2. 🎧 أصوات التركيز المحيطية (Ambient Focus Soundscapes)
- مولد صوتي توليدي نقي مبني بالكامل عبر **Web Audio API** (بدون ملفات صوتية خارجية ثقيلة، صفر تأخير):
  - 🌧️ **مطر هادئ (Deep Rain):** ترددات استرخاء دافئة.
  - 🌌 **تردد كوني 432Hz (Cosmic Drone):** تردد رنيني ثنائي الأذن لتصفية الذهن.
  - ⏳ **ساعة كلاسيكية (Analog Chrono):** دقات ميكانيكية ناعمة تحفز التركيز.

### 3. 🗄️ أرشيف الأفكار ومقياس الالتزام (Thought Vault & Streaks)
- حفظ تلقائي لكافة جلسات التفكير المكتملة مع الملاحظات وزاوية التفكير والتاريخ محلياً (`localStorage`).
- مقياس أيام متتالية للالتزام اليومي (`🔥 Streak counter`).
- إمكانية نسخ الخواطر وتصدير الأرشيف بالكامل كملف **Markdown (`.md`)** لبرامج مثل Notion و Obsidian.

### 4. 📸 بطاقة الاستوديو الفاخرة (Studio Card PNG Generator)
- تصدير بطاقة فوتوغرافية مربعة بدقة فائقة **1200×1200 بكسل** بنقرة واحدة عبر Canvas.
- تصميم ستوديو أسود داكن مع خطوط توهج زجاجية وعلامات زوايا هندسية مناسب للمشاركة على منصات التواصل.

### 5. 🌓 الوضع الليلي والنهاري (Dark & Light Mode)
- **الوضع الليلي:** استوديو فوتوغرافي أسود مطفي مع إضاءات خافتة.
- **الوضع النهاري:** عاجي تحريري ناعم وفاخر (Warm Alabaster) مريح للعين مع أسطح بيضاء وظلال ناعمة.

### 6. ✍️ خطوط تايبوجرافي مخصصة
- **العربية:** خط **ثمانية الأسود (THMANYAHSANS-BLACK)**.
- **الإنجليزية:** خط **Fraunces** بنحافة ورشاقة فائقة (`font-weight: 300`).

---

## 🛠️ التقنيات المستخدمة | Tech Stack

- **الواجهة:** React 19 + Vite
- **التصميم:** Vanilla CSS Modules + CSS Custom Properties Design Tokens
- **الصوت:** Native Web Audio API
- **الرسوم والبطاقات:** HTML5 Canvas 2D Context
- **الخطوط:** Local Custom Typography (`THMANYAHSANS` & `Fraunces`)

---

## 🚀 التشغيل المحلي | Getting Started

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي للتطوير
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build
```
